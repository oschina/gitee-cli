# Gitee CLI v0.1.0

Gitee CLI 的首个正式版本，将 Pull Request、Issue、仓库、Release、Gist 和 SSH Key 管理带到终端，并内置 AI 辅助、交互式 TUI 与自动化友好特性。

## ✨ 亮点
- 提供命令管理 Pull Request、Issue、仓库、Release、Gist 与 SSH Key。
- 在命令行搜索仓库、Issue 和用户。
- 使用个人访问令牌（PAT）登录多个 Gitee Host（公有云与私有部署）。
- 生成 Shell 补全脚本和持久化命令别名。
- 通过 `gitee api` 直接访问任意 Gitee V5 接口。
- 获得 AI 辅助：起草 PR/Issue、代码审查，以及与 OpenAI 兼容服务对话。
- 支持带快捷键和图片查看的交互式 TUI 表格。
- 通过 `gitee update` 更新 CLI（检查并安装最新版本）。

## 🚀 改进
- Issue 列表支持按创建/更新时间与方向排序。
- 别名展开支持位置参数与 Shell 管道。
- 配置支持主题、语言（英文/简体中文）、编辑器、分页器与默认仓库。
- 受支持的命令输出 JSON，便于脚本化与自动化。
- 后台版本检查（可配置，CI 环境下自动关闭）。

## 🐛 修复
- 修复纯文本表格与宽字符（CJK）对齐问题。
- 改进 AI 对话输入对宽字符的处理，并保持用户消息可见。

## 🔒 安全
- 凭据以用户专属权限（0600）存储，并在配置输出中脱敏。
- 生成的 HTTPS 克隆凭据不会暴露在 URL 或命令行参数中。
- 认证头不会跨来源或重定向转发。
- 破坏性命令需要确认或显式 `--yes` 参数。
- 远程图片下载受协议、地址、内容类型、大小、重定向次数与超时限制。
