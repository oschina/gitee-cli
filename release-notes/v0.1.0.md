# Gitee CLI v0.1.0

Initial release of the Gitee CLI, bringing pull request, issue, repository, release, gist, and SSH key management to the terminal, with AI assistance, TUI, and automation-friendly features.

## Highlights
- Manage pull requests, issues, repositories, releases, gists, and SSH keys with dedicated commands.
- Search repositories, issues, and users from the command line.
- Authenticate with multiple Gitee hosts (public and private deployments) using personal access tokens.
- Generate shell completion scripts and persistent command aliases.
- Use `gitee api` for direct access to any Gitee V5 endpoint.
- Get AI assistance for PR/issue drafts, code review, and chat with OpenAI-compatible providers.
- Enable interactive TUI tables with keyboard shortcuts and image viewing.
- Update the CLI with `gitee update` (checks and installs latest release).

## Improvements
- Issue list supports sorting by creation/update time and direction.
- Alias expansions support positional arguments and shell pipelines.
- Configuration supports themes, locale (English/Simplified Chinese), editor, pager, and default repository.
- JSON output on supported commands for scripting and automation.
- Background update checks (configurable, disabled in CI).

## Fixes
- Fixed plain-text table alignment with wide (CJK) characters.
- Improved AI chat input handling for wide characters and kept user messages visible.

## Security
- Credentials stored in files with user-only permissions (0600) and redacted from config output.
- Generated HTTPS clone credentials are not exposed in URLs or command arguments.
- Authentication headers are not forwarded across origins or redirects.
- Destructive commands require confirmation or explicit `--yes` flag.
- Remote image downloads are restricted by protocol, address, content type, size, redirect count, and timeout.
