# Gitee CLI v0.2.0

本次版本新增 Agent Skills 离线管理能力，支持 npm 一键安装，并优化了 PR diff 输出格式。

## Highlights

- **新增 `gitee skills` 命令**：内置 5 个 Agent Skill（`gitee-pr`、`gitee-issue`、`gitee-repo`、`gitee-search`、`gitee-api`），支持通过 `gitee skills install` 离线安装到 `~/.agents/skills/`，便于 AI 编程助手安全、非交互式地执行 Gitee 工作流
- **`pr diff` 支持 JSON 输出**：新增 `--json` 参数，可将 PR 变更文件以结构化 JSON 输出，便于脚本和自动化工具解析

## Improvements

- 安装 Skill 时自动清理历史废弃名称，保留其他来源的 Skill 不受干扰
- 支持通过 `--dir` 参数或 `AGENTS_SKILLS_DIR` 环境变量自定义 Skill 安装目录

## Fixes

- 修复非 TUI 环境下部分命令输出格式异常的问题
