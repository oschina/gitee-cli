# Gitee CLI v0.2.3

优化多 Host 场景下的默认 Host 自动选择机制，减少私有部署用户重复指定 `--hostname` 的操作。

## Improvements

- **自动默认 Host**：当仅登录了私有 Gitee 实例且未配置 `gitee.com` 凭证时，所有命令自动使用该私有实例作为默认 Host，无需每次添加 `--hostname`
- **登录即设默认**：使用 `gitee auth login --hostname <host>` 登录私有实例后，该实例自动成为后续命令的默认 Host
- **登出自动重置**：执行 `gitee auth logout` 登出当前默认私有实例时，自动恢复默认 Host 为 `gitee.com`
