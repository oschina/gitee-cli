# Gitee CLI v0.3.3

本次发布修复了通过完整 HTTPS URL 克隆仓库时无法复用已保存令牌的问题。

## Fixes

- 使用 `gitee repo clone https://gitee.com/owner/repo` 等完整 HTTPS 地址克隆时，现在会按 URL 主机查找已保存令牌并自动认证，不再在已配置令牌时退回交互式凭据提示。
- `owner/repo` 与完整 HTTPS URL 的令牌认证行为已统一；HTTPS URL 会保持原地址形式，并支持带 `.git` 后缀的仓库地址。
- SSH、HTTP、带端口的 HTTPS 地址以及未配置令牌的主机仍按 Git 原有方式处理，不会额外注入认证信息。

## Security

- 通过完整 HTTPS URL 克隆时，已保存令牌仅通过临时 Git 环境配置传递，不会出现在命令行参数或克隆后的 remote URL 中。
