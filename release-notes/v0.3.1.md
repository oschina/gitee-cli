# Gitee CLI v0.3.1

本版修复企业项目组（project group）仓库路径解析与服务端错误处理问题。

## Highlights
- 修复 `issue create`/`edit`/`close`/`reopen`/`assign` 无法处理企业三段式仓库路径（`<ent>/<group>/<repo>`）的问题：owner/repo 现按最后一个 `/` 切分，创建与更新类请求改为使用完整的命名空间路径并配合 `repo` 表单字段，行为与读接口及 `pr create` 保持一致。

## Fixes
- 修复 remote URL 解析：忽略 `https://<user>@host/...` 中的 userinfo，并支持企业三段式路径（HTTPS 与 SSH 形式均可识别）。
- 修复 `issue create` 在服务端返回错误时静默成功的问题：识别 `base`/`messages`/`message` 错误信封（含 HTTP 2xx 携带错误体的场景），按失败返回非零退出码，不再输出全零对象。
- 修复仓库存在 remote 但无法解析时误用 `default_repo` 的问题，避免命令静默操作到无关仓库。
- 改进仓库解析报错信息：区分「不是 git 仓库」「没有 remote」「有 remote 但无法解析」，并在最后一种情况下回显实际读到的 URL（凭据已脱敏）。

## Docs
- 新增 Gitee CLI 使用指南，覆盖安装、认证、命令发现、常用工作流与内置 Agent Skills。
- 补充 JSON 字段选择说明（`--json=field1,field2`、`--json=list`），并提示 PowerShell 下需为 `--json` 的值加引号。
