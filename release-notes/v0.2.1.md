# Gitee CLI v0.2.1

Fixes alias examples to prevent shell expansion issues.

## Improvements

- Added an official install script (`scripts/install.sh`) for macOS and Linux that automatically detects your platform, downloads the latest release from Gitee, verifies the SHA-256 checksum, and installs the `gitee` binary to your PATH.
- The install script supports pinning a specific version, customizing the install directory, and authenticating with a GITEE_TOKEN for private repositories.
- Updated all alias help text and documentation to use single quotes around expansions, ensuring positional variables like `$1` and command substitutions like `$(...)` are handled correctly by the shell.

## Fixes

- Corrected alias examples in help output and documentation that previously used double quotes, which caused shells to expand variables prematurely and store incorrect aliases.
