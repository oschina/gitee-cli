# Gitee CLI v0.2.2

本次版本新增了 Pull Request 和 Release 编辑能力，增强了 Issue 编辑功能，提升了 Release 创建的可靠性，并加入新的 Agent Skill。

## 主要更新

- 新增 `gitee pr edit` 命令，支持非交互式更新字段、显式清空描述、切换草稿状态以及 JSON 输出。
- 新增 `gitee release edit` 命令，支持通过 ID 或标签查找 Release，并更新标签、名称、正文和预发布状态，同时支持 JSON 输出。
- 增强 `gitee issue edit`，新增标签和里程碑编辑能力，并支持显式清空描述、负责人和标签。
- 新增 `gitee-release` Agent Skill，用于管理 Release 生命周期，并为高风险操作提供必要的安全确认。

## 功能改进

- 使用 `gitee release create` 且未指定 `--target` 时，现在会自动获取并使用仓库默认分支。
- Agent Skills 在通过 API 更新或删除资源前会进行二次确认；遇到命令暂不支持的操作时，可通过 `gitee api --search` 查找端点 Schema 并继续调用。
- Issue、Pull Request 和 Release 的交互式编辑表单现在会预加载当前值，并支持清空字段。
- 删除中英文文档中已经失效的 Gist 相关说明。

## 问题修复

- 修复 Issue 编辑时将未传字段序列化为非预期默认值的问题，未指定的字段现在会保持原值。
- 修复 `gitee release create` 未指定 `--target` 时创建失败的问题。
- 修正中文 README 安全问题报告说明中的标点。
