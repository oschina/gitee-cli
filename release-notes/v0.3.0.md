# Gitee CLI v0.3.0

本版新增 Gitee Go 流水线支持，并完善私有化环境适配、项目构建查询与流水线权限校验。

## Highlights
- 新增 Gitee Go 流水线命令，支持管理仓库 GitOps 流水线和项目/企业流水线，包括流水线列表与详情、运行、构建历史、取消与重跑、阶段与任务、提交 YAML、插件与模板等。
- 项目流水线支持交互式创建与更新向导，可按插件 scheme 填写参数表单，生成完整配置后可选择直接提交或在编辑器中修改。

## Improvements
- 自动适配 Gitee Go API 网关路径，支持公共 gitee.com、本地开发域名、私有化/企业版部署，并可通过 go_api_host 配置项覆盖。
- 对 Gitee Go 额度与权限错误提供更清晰提示：配额不足时不再重试并说明套餐/用量，权限不足时提示检查登录与授权。
- 流水线列表、参数、插件、模板和请求命令统一使用带边框表格输出，解析异常改为表格下方警告，便于阅读。
- AI 对话的欢迎、退出、告别和错误提示已国际化，英文语言环境不再显示硬编码中文。
- 文档补充私有化部署令牌登录说明：当 Access Token 创建地址不可用时，可手动创建 Personal Access Token 并选择直接粘贴令牌。

## Fixes
- 修复项目流水线构建历史与最近构建因流水线标识格式错误而返回空列表的问题；纯数字标识和带前缀标识均可识别。
- 修复流水线配置解码对字符串数组参数和字符串 Pull Request ID 不兼容的问题，避免 JSON 解析失败。
- 修复构建列表页码或每页数量非法时未在请求前校验的问题，减少分页参数导致的异常输出。
- 修复仓库流水线构建、阶段、任务等命令帮助示例缺少必需仓库定位参数的问题，使示例与命令要求一致。
- 修复中文提交流水线 YAML 确认提示中仓库与分支顺序错误的问题。

## Security
- 应用项目流水线版本前增加历史版本归属校验，防止将不属于当前项目的流水线版本应用到目标项目。
