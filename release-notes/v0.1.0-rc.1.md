# Gitee CLI v0.1.0-rc.1

Initial public release candidate for the Gitee command-line interface,
providing core repository workflows, API exploration, and non-interactive
automation support.

## Highlights

- **Core Gitee workflows**: Manage pull requests, issues, repositories,
  releases, gists, SSH keys, and raw API calls from the terminal.
- **Interactive TUI mode**: Browse lists with rich tables, navigate with
  keyboard shortcuts, and open items in a browser.
- **Smart PR workflow**: `gitee pr checkout` fetches and switches branches in
  one step, while `gitee pr fetch` supports fetch-only operations.
- **AI assistance**: Generate PR descriptions, issue reports, and code reviews
  using any configured OpenAI-compatible API.
- **Multi-host support**: Log in to multiple Gitee instances with per-host
  credentials.
- **Command aliases**: Create shortcuts such as
  `gitee alias set prs "pr list -s open"`.
- **Cross-platform distribution**: Install prebuilt binaries for Linux, macOS,
  and Windows on amd64 or arm64, or install through npm.

## Improvements

- **Non-interactive and CI support**: Authentication accepts tokens from stdin,
  SSH keys can be piped with `--file -`, destructive operations require
  explicit confirmation, and TUI detection respects the actual terminal state.
- **JSON output and field selection**: List and view commands consistently
  support selecting nested output fields and discovering available fields.
- **API command enhancements**: Raw API calls support pagination, multi-word
  OpenAPI search, configurable API specifications, and richer endpoint details.
- **Version and branding**: Version output now includes clearer build and
  repository information.
- **Usage identification**: HTTP requests use a versioned
  `gitee-cli@version` user agent to support service-side usage statistics.

## Security

- Credentials are stored with restricted permissions and redacted in config
  output.
- Secret configuration supports hidden input and stdin so tokens do not need to
  appear in shell history or process arguments.
- Release artifacts include checksums, and the publishing workflow validates
  the build before upload.

## Fixes

- Release creation now passes the exact target commit required by Gitee.
- Missing Release responses for existing tags are handled correctly.
- Pull request assignees use the API-aligned `--assignees` flag.
