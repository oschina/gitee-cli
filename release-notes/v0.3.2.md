# Gitee CLI v0.3.2

本版修复 `gitee search repos` 因旧搜索端点失效而无法返回结果的问题。

## Highlights
- `gitee search repos` 改用 Gitee 新的搜索接口 `/search/repos`，仓库搜索恢复可用；支持 `--language` 过滤，并通过 `--page`、`--limit` 分页。
- 兼容性变更：`gitee search repos` 不再支持 `--owner`、`--fork`、`--sort`、`--order`（新接口不支持这些过滤与排序），请改用关键词、`--language`、`--page`、`--limit`。

## Fixes
- 修复 `gitee search repos` 恒返回空结果的问题：原 `/search/repositories` 端点已失效，现改用 `/search/repos`。
- 搜索结果沿用既有 CLI 输出字段：`full_name`、`html_url`、`stargazers_count`、`forks_count`、`language`、`license`、`updated_at` 等；仅旧端点提供、新服务不含的字段（如 `private`、`ssh_url`、`default_branch`、`permission`）不再填充。

## Docs
- 命令帮助、中英文使用文档，以及 `gitee-search`、`gitee-api` 技能示例已同步为新的仓库搜索用法。
